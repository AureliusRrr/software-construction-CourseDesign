# V1.1 用户注册功能

本版本在 V1.0 固定账号登录原型上进行增量开发，删除硬编码账号，改为在运行期间动态注册和登录。

## 功能

- 首页菜单：登录、注册、退出
- 使用 `HashMap<String, String>` 在内存中保存用户账号和密码
- 用户名非空校验
- 密码非空及最少 6 位校验
- 用户名唯一性校验
- 注册成功后可在同一次程序运行期间登录
- 区分用户不存在、密码错误和输入为空等失败场景

## 环境

- JDK 8 或更高版本
- 不依赖第三方库

## 编译与运行

在 `V1.1` 目录执行：

```shell
javac -encoding UTF-8 -d out src/SystemMain.java
java -cp out SystemMain
```

用户数据目前仅保存在内存中，退出程序后会丢失；文件持久化将在后续版本实现。
