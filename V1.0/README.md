# V1.0 项目初始化

本版本实现课程任务书 V1.0 要求的控制台登录原型。

## 功能

- 从控制台输入账号和密码
- 区分管理员与学生身份
- 输出登录成功或失败提示

固定测试账号：

| 身份 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `123456` |
| 学生 | `student` | `123456` |

## 环境

- JDK 8 或更高版本
- 不依赖第三方库

## 编译与运行

在 `V1.0` 目录执行：

```shell
javac -encoding UTF-8 -d out src/SystemMain.java
java -cp out SystemMain
```

本阶段按照任务书要求，将全部逻辑保留在 `SystemMain` 中，暂不进行分层、实体封装或工具类抽取。
