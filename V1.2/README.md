# V1.2 面向对象用户实体重构

本版本在 V1.1 动态注册与登录功能上进行增量重构，引入 `User` 实体类封装用户数据，并将内存存储结构从键值对升级为用户对象列表。

## 功能

- 新增 `User` 实体类，包含用户名、密码、角色和注册时间
- 提供无参构造、有参构造、完整的 getter/setter 和 `toString()`
- 使用 `List<User>` 保存运行期间注册的用户
- 新注册账号默认角色为 `student`
- 注册时自动记录当前时间，并打印完整用户对象信息
- 登录和用户名唯一性校验改为基于用户对象查询
- 保留 V1.1 的非空校验、密码长度校验和登录失败提示

## 设计说明

`User` 只承载数据，不包含注册、登录或校验等业务逻辑，体现封装原则和单一职责原则。业务流程仍由 `SystemMain` 负责，为后续分层重构保留清晰边界。

## 环境

- JDK 8 或更高版本
- 不依赖第三方库

## 编译与运行

在 `V1.2` 目录执行：

```shell
javac -encoding UTF-8 -d out src/User.java src/SystemMain.java
java -cp out SystemMain
```

用户数据目前仅保存在内存中，退出程序后会丢失；文件持久化将在后续版本实现。
